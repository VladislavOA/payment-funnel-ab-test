# A/B-тест платёжной воронки (T-Банк, pet-проект)

Анализ A/B-эксперимента над флоу оплаты: влияет ли новая версия (группа B) на конверсию в успешный платёж по сравнению с контролем (группа A).

## Данные

Файл [`data.xlsx`](data.xlsx) содержит два листа:

| Лист | Содержание |
|---|---|
| Пользователи | `user_id`, `group` (A/B), `age`, `city`, `device_type` (android/ios) — ~1500 пользователей, поровну в группах |
| Платежи | `payment_id`, `user_id`, `group`, временны́е метки четырёх шагов воронки — ~2660 платёжных сессий (апрель 2024) |

Шаги воронки платежа:

1. `step1_opened` — открыл экран оплаты
2. `step2_entered` — ввёл данные
3. `step3_confirmed` — подтвердил
4. `step4_success` — платёж успешен

Пустое значение шага означает, что пользователь до него не дошёл.

## Что делается в ноутбуке

Весь анализ — в [`AB_test.ipynb`](AB_test.ipynb):

1. **Очистка данных**: пропуски в `city` (мода) и `group`/`user_id` (строки удаляются), аномальные возрасты (`-5`, `150`) заменяются медианой.
2. **Проверка баланса групп**: размеры групп, распределение возраста (критерий Колмогорова–Смирнова), доля 20-летних (точный критерий Фишера).
3. **Конверсия на уровне пользователя** — отношение `успешные платежи / открытые платёжные сессии`. Поскольку у пользователя может быть несколько платежей, а метрика — отношение двух случайных величин, дисперсия считается **дельта-методом**; затем z-тест и 95% ДИ для разницы B − A.
4. **Анализ воронки по шагам**: тот же дельта-метод для каждого перехода 1→2, 2→3, 3→4 и для воронки целиком, плюс визуализация.
5. **Логистическая регрессия** успеха платежа от группы, города, устройства и возраста со стандартными ошибками, кластеризованными по `user_id`; odds ratio с доверительными интервалами.

## Результаты

| Шаг воронки | Конверсия A | Конверсия B | Разница (B − A) | p-value |
|---|---|---|---|---|
| 1 → 2 (открыл → ввёл данные) | 81.13% | 88.38% | +7.25 п.п. | 3.7e-07 |
| 2 → 3 (ввёл → подтвердил) | 71.47% | 80.40% | +8.93 п.п. | 3.2e-07 |
| 3 → 4 (подтвердил → успех) | 85.90% | 90.62% | +4.72 п.п. | 2.8e-03 |
| **Итого 1 → 4** | **49.81%** | **64.40%** | **+14.59 п.п.** (95% ДИ [10.9; 18.3]) | 1.2e-14 |

- Итоговая конверсия в группе B выше на **14.6 п.п.** (относительный рост ≈ **+29%**).
- Улучшение наблюдается на каждом шаге воронки, сильнее всего — на шаге ввода и подтверждения данных.
- В регрессии с контролем на город, устройство и возраст эффект группы B сохраняется: **OR ≈ 1.83** (95% ДИ [1.56; 2.13]). Город и устройство значимого влияния не оказывают; возраст слабо отрицательно связан с успехом (OR ≈ 0.99 за год).
